# Instructions for implementation agents

Treat the pinned Fold Spec schema, normative specification, and fixtures as one
contract. Report contradictions; do not relax validation or motion semantics to
make a test pass.

Preserve original IDs, exact operation/run mappings, face winding, material
sides, localized text, rights, and limitations. Do not substitute decorative
meshes for missing motion or claim physical validation, screen-reader
certification, or a full solver.

Keep the npm runtime independent of Tailwind and shadcn. Registry compositions
may depend on host-owned shadcn components. Maintain controlled and uncontrolled
behavior, SSR-safe imports, bounded parsing, resource disposal, and text
fallbacks.

When updating the spec snapshot, record upstream commit and hashes in
`tests/fixtures/PROVENANCE.md`. Package checks must reject unexpected tarball
files. Do not fabricate published package URLs, release records, test counts, or
browser/accessibility evidence.
